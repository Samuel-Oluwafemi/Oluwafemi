# Oluwafemi — SEO Strategy

## Homepage Title

Samuel Oluwafemi — Frontend Developer & Digital Product Builder

---

# Meta Description

Frontend developer building modern, conversion-focused websites and digital experiences for businesses, creators and products.

---

# Primary Search Intent

The portfolio should be discoverable for searches around:

- frontend developer
- web developer
- React developer
- frontend developer Nigeria
- React developer Nigeria
- website developer Nigeria
- freelance frontend developer
- business website developer
- React website developer
- modern website developer

Do not keyword-stuff the website.

---

# PROJECT SEO

Each case study should have its own:

- title
- description
- Open Graph metadata
- canonical URL where appropriate

Example:

Velora:

`Velora — E-commerce Experience | OluwafemiX`

---

# TECHNICAL SEO

Implement:

- semantic HTML
- descriptive page titles
- meta descriptions
- Open Graph
- Twitter/X card metadata
- sitemap
- robots.txt
- canonical URLs where needed
- meaningful image alt text

---

# PERFORMANCE SEO

Optimize:

- image sizes
- font loading
- JavaScript bundles
- animations
- lazy loading
- layout shifts

Avoid heavy third-party scripts.

---

# IMAGE ALT TEXT

Alt text should describe the actual image.

Bad:

`website`

Better:

`Velora e-commerce product grid showing product cards and navigation`

Do not stuff keywords into alt text.
